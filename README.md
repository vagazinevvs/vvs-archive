# VVS Archive

[💎VVS Archive](https://vagazinevvs.github.io/vvs-archive/)

A fan-made web tool for browsing and managing your photocard collection.

## How to Use

1. **Browse Collection**: View and search through the catalog of photocards directly from the web interface.
2. **Filter & Sort**: Use the available filters and sorting options to quickly find specific items by member, album, or status.
3. **Export Template**: Export customized template based on current filtered cards.
4. **Local Management**: All custom card labeling, notes, and organizational tags are saved locally within your browser environment.

## Keyboard Shortcuts

* **` /`**: Focus search input
* **`d`**: Toggle dark/light theme

### Grid Mode

* **`← →`**: Previous / Next page
* **`t / g / h / s / y`**: Toggle member filters (Taehwan, GON, Hyesung, Sungkook, Yeongkwang)
* **`c`**: Reset all filters
* **`n`**: Toggle sort order (Newest / Oldest)
* **`q`**: Export template

### Preview Mode

* **`← →`**: Previous / Next card
* **`Space`**: Flip card
* **`o / l`**: Label HAVE / WANT
* **`Esc`**: Close card preview

# VVS 收藏集管理工具

[💎VVS Archive](https://vagazinevvs.github.io/vvs-archive/)

粉絲製作的小卡瀏覽與管理網頁工具。

## 使用說明

1. **瀏覽收藏**：直接透過網頁介面檢視與搜尋小卡圖錄。
2. **篩選與排序**：使用篩選與排序功能，依成員、專輯或狀態快速尋找特定項目。
3. **匯出圖鑑**：依照目前使用的篩選條件匯出帶有標記的圖鑑。
4. **本機管理**：所有自定義整理標籤僅儲存於您的瀏覽器本機環境中。

## 鍵盤快速鍵

* **` /`**: 搜尋輸入
* **`d`**: 切換深色 / 淺色模式

### 瀏覽模式

* **`← →`**: 上 / 下一頁
* **`t / g / h / s / y`**: 篩選成員 (泰煥、GON、慧成、成國、泳光)
* **`c`**: 清除所有篩選條件
* **`n`**: 切換排序 (最新 / 最舊)
* **`q`**: 匯出圖鑑

### 預覽模式

* **`← →`**: 上 / 下一張卡片
* **`Space`**: 翻轉卡片 (瀏覽卡背)
* **`o / l`**: 標記 擁有 / 想要
* **`Esc`**: 取消搜尋框焦點或關閉卡片預覽

## 版權聲明與免責聲明

本專案為個人整理用途而建立之獨立、非營利歸檔工具。

* 所有官方圖片、標誌、團體名稱及相關智慧財產權均歸其各自之經紀公司與版權所有者所有。

# VVS 아카이브

[💎VVS Archive](https://vagazinevvs.github.io/vvs-archive/)

팬이 제작한 포토카드 브라우징 및 관리 웹 도구.

## 사용 방법

1. **컬렉션 탐색**: 웹 인터페이스를 통해 직접 포토카드 카탈로그를 조회하고 검색합니다.
2. **필터 및 정렬**: 멤버, 앨범, 상태별로 특정 아이템을 빠르게 찾기 위해 필터 및 정렬 옵션을 사용합니다.
3. **도감 내보내기**: 현재 사용 중인 필터 조건에 따라 표시가 있는 도감을 내보냅니다.
4. **로컬 관리**: 모든 커스텀 카드 라벨, 메모 및 정리 태그는 브라우저 로컬 환경에만 저장됩니다.

## 키보드 단축키

* **` /`**: 검색창 포커스
* **`d`**: 다크/라이트 테마 전환

### 그리드 모드

* **`← →`**: 이전 / 다음 페이지
* **`t / g / h / s / y`**: 멤버 필터 토글 (태환, 곤, 혜성, 성국, 영광)
* **`c`**: 모든 필터 초기화
* **`n`**: 정렬 순서 전환 (최신순 / 오래된순)
* **`q`**: 템플릿 내보내기

### 미리보기 모드

* **`← →`**: 이전 / 다음 포토카드
* **`Space`**: 카드 뒤집기
* **`o / l`**: 소장 / 위시 라벨링
* **`Esc`**: 검색창 포커스 해제 또는 카드 미리보기 닫기
